PERBAIKI SESUAIKAN DENGAN TASK YANG KAMU KERJAKAN

# CARA 1 clone

## FRONTEND

1. root : client
2. run 'npm install'
3. edit dengan tag docs/ (sebagai scope)
4. test
5. add commit push, usahakan tiap fitur harus memiliki branch tersendiri

## backend

1. root : server
2. run 'composer install'
3. edit dengan tag docs/ (sebagai scope)
4. test
5. add commit push, usahakan tiap fitur harus memiliki branch tersendiri

# CARA 2 pull

1. root : nama folder project
2. jalankan git pull origin main
3. di vm klik esc 1 kali lalu ketik :wq untuk menyimpannya
4. setelah pull berhasil, edit dengan tag docs/ (sebagai scope)
5. test
6. add commit push, usahakan tiap fitur harus memiliki branch tersendiri
